# 毕业论文项目 — 河南极端降水与大气环流关系

## 项目概述

南京信息工程大学（NUIST）大气科学学院本科毕业论文。研究河南省极端降水事件与大气环流之间的关联，使用多种气象数据集和统计分析方法。

## 项目规模
约 60+ 个 Python 脚本，按分析阶段组织。

## 数据源

| 数据集 | 用途 | 来源 |
|--------|------|------|
| **ERA5** | 再分析数据，环流场、风场、位势高度 | ECMWF |
| **GPCC** | 全球降水气候学中心降水数据 | DWD |
| **HadISST** | 海冰和海表温度数据 | UK Met Office |
| **CN05.1** | 中国区域网格化观测数据 | 中国气象局 |

## 分析方法

| 方法 | 用途 |
|------|------|
| **EOF 分析** | 经验正交函数分解，提取降水主要模态 |
| **SVD 分析** | 奇异值分解，分析降水和环流场的耦合模态 |
| **MK 检验** | Mann-Kendall 趋势检验 |
| **合成分析** | 暴雨个例合成环流场 |
| **相关场分析** | 降水与环流指数的关联 |
| **水汽通量诊断** | 水汽与动力距平通量散度 |

## 论文格式
- 根据南信大撰写规范格式化
- 参考文献采用 GB/T 7714-2015 格式
