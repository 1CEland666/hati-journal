# GitHub 账号清理

## 事件发现

2026-04-30 发现旧账号下存在非本人操作的异常行为。

| 项目 | 内容 |
|------|------|
| 旧账号 | 用户此前使用的 GitHub 账号 |
| 问题仓库 | 被自动 fork 的盗版影视站项目 |
| 性质 | **免费影视站搭建工具**（涉嫌版权侵权）|

## 调查结论

### 时间线
账号创建后数分钟内即被自动 fork 了该项目，之后零活动、零提交。

### 判断依据
- ❌ 用户从未做过任何影视相关项目
- ❌ 仓库中 0 条提交来自用户本人
- ✅ 该操作的自动化特征明显（注册→fork 间隔极短）

### 结论
账号被脚本/机器人滥用。非用户本人操作。

## 处理结果

| 步骤 | 状态 |
|------|------|
| 调查确认 | ✅ 非本人操作 |
| 删除旧账号 | ✅ 已删除 |
| 注册新账号 | ✅ 新账号已就绪 |
| 建立新仓库 | ✅ 本仓库（私有）已创建 |

## 安全建议

1. 不同平台使用不同密码
2. 启用两步验证（2FA）
3. PAT 使用最小权限原则
4. 定期检查账号状态和仓库列表
